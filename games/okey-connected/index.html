Okey Connected

A 2D tile game by Alemdar Labs, a game and app studio based in Istanbul, Turkey.

App ID: com.alemdarlabs.okeyconnected

About the game

Okey Connected brings the traditional game of Okey to a digital table. Arrange numbered tiles into sets and runs, join online games, or play with computer-controlled opponents. Player profiles, friends, and saved game progress support the connected experience.

The game is in development. Release dates and store availability have not been announced.

Player support

For help with the game or a privacy request, email info@alemdarlabs.com. Include the game name and your platform. Do not send passwords or sign-in codes.
